# Mediator(中介者)

讓一群物件**不直接互相引用**,改透過一個中介者溝通,把「誰要通知誰」集中在一處。

本範例:聊天室,使用者只認識聊天室,`send` 交給聊天室廣播給其他人。

## 角色

| 角色 | 對應本範例 | 職責 |
|------|-----------|------|
| **Mediator** | `ChatRoom` | 記錄成員,依加入順序轉發訊息,跳過發送者 |
| **Colleague** | `User` | 只持有聊天室,不認識其他使用者;建構時自動 `join` |

`User` 之間沒有互相引用,新增或移除成員只動 `ChatRoom`。

## 執行

cd javascript && node --test 17_mediator/*.test.js
