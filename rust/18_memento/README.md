# Memento(備忘錄)

在**不暴露內部狀態**的前提下,把物件的狀態存成快照,之後可以還原。

本範例:文字編輯器。`save` 取得快照,繼續編輯後用 `restore` 回到存檔當時的內容。

## 角色

| 角色 | 對應本範例 | 職責 |
|------|-----------|------|
| **Originator** | `Editor` | 擁有狀態,負責產生與還原快照 |
| **Memento** | `Memento` | 狀態快照,欄位私有 |
| **Caretaker** | 呼叫端(測試) | 保管快照,不看內容 |

## Rust 慣用寫法

`Memento` 的欄位是私有的:定義它的模組之外(例如使用這個 crate 的程式碼)讀不到也改不了,這是**編譯器保證**的不透明;JS 版的快照只是凍結(`Object.freeze`),內容仍讀得到,「只把它交回 `restore`」要靠約定。

`restore` 的參數是 `Memento` 本身(取得所有權),而 `Memento` 沒有實作 `Clone`,所以同一份快照不能被還原兩次;還原第二次會是編譯錯誤。

## 執行

```sh
cd rust && cargo test -p memento
```
